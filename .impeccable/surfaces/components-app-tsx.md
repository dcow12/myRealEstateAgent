# Surface: PlotTwist main screen (components/App.tsx, components/TownScene.tsx)

Mode: Operate. Build path: code-led (Operate surface). Direction is brief-pinned by the user: production SaaS restraint in the class of Linear, Vercel, Stripe Dashboard, GitHub; Inter or Geist; neutral palette with one purposeful accent; no emojis, glass, gradients or promotional copy. concept-seed was not run because the brief pins the direction.

Audience and job: planners and housing staff (homeowners secondary) find a lot, read its verdict and limiting rule, test rule changes citywide, and question one specialised agent at a time.

## Direction contract

THESIS: A planning workstation over a real 3D city: docked panels, tabular facts, and an agent console whose every answer shows the tool calls that produced it. Refuses the floating-cards-over-a-map dashboard and the chatbot-with-mascots arrangement.

OWN-WORLD: Cool neutral ground (zinc-like grays), 1px hairline borders, 6px control and 8px panel radii, opaque surfaces, near-flat elevation. Geist for UI, Geist Mono for measurements, counts and tool names. One accent, cobalt, for primary action, selection, focus and the proposed-cottage geometry on the map. Verdict colours (fits, almost, blocked, review) are muted state colours used only where they encode a verdict. Agents are square monograms with a one-word function name.

STORY: The user sees the citywide count and its breakdown, picks or searches a lot, reads its key facts and limiting rule, adjusts rules and sees the delta, and asks the relevant agent, reading both the answer and its trace.

FIRST VIEWPORT: 48px top bar (wordmark, city, address search, model status, theme). Left 320px sidebar: verdict table with counts and shares, rule controls, selected-lot facts. Centre: the map canvas with a compact legend. Right 384px agent console: agent tabs, agent header with capabilities and state, transcript, composer. Primary action: search and the composer.

FORM: Category-standard product shell (pinned canon, position 1 of 1; the user's brief pins the direction, so concept-seed was not rolled, per new-work's pinned-direction rule). Signature move: the tool-call trace under each agent answer, monospace, each call expandable to its full arguments, so the "code decides" claim is checkable. seed: none (pinned)

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
